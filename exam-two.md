2) Types of Physical Network Topologies
Answer: Network topologies define how devices are interconnected physically or logically.
Bus Topology:
- Single communication backbone
- Simple but prone to single point of failure
- Example: Early Ethernet networks
Star Topology:
- Central hub/switch connects all nodes
- Easy troubleshooting
- Modern standard for LANs
Mesh Topology:
- Full mesh: All nodes interconnected
- Partial mesh: Critical connections only
- High reliability but expensive
Hybrid Topologies:
- Combine multiple topologies
- Balance cost and performance
- Common in enterprise networks

4) Common Security Misconfiguration
Answer: Security misconfigurations remain a top vulnerability according to OWASP.
Server-Level Issues:
- Default credentials
- Unnecessary services
- Verbose error messages
Application-Level Issues:
- Insecure headers
- Improper session handling
- Hardcoded secrets
Prevention Strategies:
- Configuration hardening
- Regular audits
- Principle of least privilege
Emerging Threats:
- API security gaps
- Container misconfigurations
- Cloud storage exposures
