1) Difference between internet and Web.
Answer: The internet is the global network infrastructure that connects millions of private, public, academic, business, and government networks, while the web (World Wide Web) is an information system that operates over the internet using HTTP/HTTPS protocols.
- The internet provides the foundational network infrastructure including physical cables, routers, switches, and servers
- The web is an application layer service that uses browsers to access interconnected documents via URLs and hyperlinks
- Other internet services include email (SMTP), file transfer (FTP), remote login (SSH), and voice/video communication (VoIP)
- Key protocols: TCP/IP for internet communication, HTTP/HTTPS for web, DNS for address resolution
- Historical development: ARPANET (1969), TCP/IP standardization (1983), web invention (1989 by Tim Berners-Lee)

- Performance optimization techniques
- Accessibility compliance (WCAG standards)
Design Process:
- Research and user personas
- Wireframing and prototyping
- User testing and iteration

2) Types of Physical Topologies.
Answer: Network topologies define the physical or logical arrangement of nodes in a network, each with specific characteristics and use cases.
Common Topologies:
1. Bus Topology:
   - Single backbone cable connects all devices
   - Terminators prevent signal reflection
   - Simple but has single point of failure
   - Example: Early Ethernet 10Base2 networks

2. Star Topology:
   - Central switch/hub connects all nodes
   - Easy to manage and troubleshoot
   - Single point of failure at hub
   - Standard for modern office networks

3. Ring Topology:
   - Devices connected in circular fashion
   - Data travels in one direction
   - Token passing prevents collisions
   - Used in some industrial networks

4. Mesh Topology:
   - Full mesh: Every device connects to every other
   - Partial mesh: Only critical connections
   - High redundancy but expensive
   - Common in wireless and IoT networks

Emerging Trends:
- Software-defined networking (SDN)
- Cloud-based virtual topologies
- Hybrid approaches combining multiple topologies

- Performance optimization
Career Paths:

- Frontend/Backend Developer
- Full-stack Developer
- UX Engineer (hybrid role)

4) Security Misconfiguration.
Answer: Security misconfigurations are among the most common vulnerabilities that attackers exploit in web applications.
Common Issues:
- Default credentials and configurations
- Unnecessary enabled services and features
- Improper file and directory permissions
- Outdated software with known vulnerabilities
- Verbose error messages revealing system info
Prevention Strategies:
- Implement principle of least privilege
- Regular security audits and scanning
- Automated configuration management
- Security headers (CSP, HSTS, X-XXS-Protection)
OWASP Recommendations:
- Secure installation processes
- Hardened configuration baselines
- Regular patching and updates
Emerging Threats:
- Cloud service misconfigurations
- Container and orchestration security
- API security vulnerabilities
Best Practices:
- Change default credentials immediately
- Disable unnecessary features
- Implement proper logging and monitoring
- Regular security training for staff
