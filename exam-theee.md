1. Write what you know about:
1) Types of networks according to engineering design.
Answer: Network engineering designs are categorized based on their physical and logical connection patterns.
Bus Topology:
- Single backbone cable with terminators
- Simple but has collision domain issues
- Example: Early Ethernet networks
Star Topology:
- Central hub/switch connects all nodes
- Easy troubleshooting
- Modern standard for LANs
Mesh Topology:
- Full mesh: All nodes interconnected
- Partial mesh: Critical connections only
- High reliability but expensive
Emerging Designs:
- Software-defined networking
- Cloud-based topologies
- Hybrid approaches

(2) Network layers.
Answer: Network protocols are organized in layered architectures.
OSI Model (7 Layers):
1. Physical - Cables, signals
2. Data Link - MAC addressing
3. Network - IP addressing
4. Transport - TCP/UDP
5. Session - Connections
6. Presentation - Data formats
7. Application - End-user services
TCP/IP Model (4 Layers):
1. Network Access
2. Internet
3. Transport
4. Application
Key Protocols:
- HTTP, FTP, DNS
- SSL/TLS
- DHCP

- HTTP, FTP, DNS

II. Draw a table and write the number of the statement and its answer true (T) or false (F).
1) Data unit is a general term for data in all layers of the network.
(وحدة البيانات هو مصطلح عام للبيانات في جميع طبقات الشبكة)
Answer: False - Each layer has specific terms (bits, frames, packets, segments)

2) There is no difference between the internet and the local network
(لا يوجد فرق بين الإنترنت والشبكة المحلية)
Answer: False - Internet is global, LAN is local (home/office network)

3) Coaxial cable is a cable consisting of several copper wires inside a plastic sheath
(الكابل المحوري هو كابل يتكون من عدة أسلاك نحاسية داخل غلاف بلاستيكي)
Answer: True - Correct description of coaxial cable structure

4) If the Rx is 200 times stronger than the Tx, then the level of gain in the signal is 25 dB.
(إذا كان الاستقبال أقوى 200 مرة من الإرسال، فإن مستوى كسب الإشارة هو 25 ديسيبل)
Answer: False - Gain = 10*log10(200) ≈ 23dB

5) If the Tx is 100 times stronger than the Rx, then the level of loss in the signal is 30 dB.
(إذا كان الإرسال أقوى 100 مرة من الاستقبال، فإن مستوى فقدان الإشارة هو 30 ديسيبل)
Answer: False - Loss = 10*log10(100) = 20dB

6) If the frequency is 50 cycles/second, the cycle time for the variable city current signal is 35 sec.
(إذا كان التردد 50 دورة/ثانية، فإن زمن الدورة لإشارة التيار المتغير هو 35 ثانية)
Answer: False - Cycle time = 1/50 = 0.02 seconds

8) Peer-to-Peer is less expensive but does not work effectively between devices.

9) The protocols are responsible for dividing the data into packets in the transmitter device.
